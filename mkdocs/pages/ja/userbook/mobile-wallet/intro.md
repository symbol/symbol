# Symbol モバイルウォレット

![ようこそ画面](create-wallet-0.webp){ .tutorial-result }

Symbol モバイルウォレットは、Android または iOS デバイスから Symbol ブロックチェーンを操作するためのアプリケーションです。
複数の [アカウント](default:アカウント) の管理、トランザクションの送受信、<XYM:> トークンの他のブロックチェーンへのブリッジなどを行うことができます。

## ウォレットとアカウント

Symbol モバイルウォレットアプリでは、**ウォレット**とは、モバイルデバイス上で 1 つ以上のアカウントを管理するために必要な情報を保存するローカル設定です。
[Symbol デスクトップウォレット](../desktop-wallet/install.md) の [プロファイル](default:プロファイル) に似ています。

各ウォレットには次のものが含まれます。

* 任意の数の[シードアカウント](default:シードアカウント)を派生できる [ニーモニックフレーズ](default:ニーモニックフレーズ)。
* アプリ上で管理される 1 つ以上のアカウント。[シードアカウント](default:シードアカウント)と[外部アカウント](default:外部アカウント)を含みます。
* デバイス上のウォレットへのアクセスを保護する PIN コード。

シードアカウント
:   ウォレットの [ニーモニックフレーズ](default:ニーモニックフレーズ) から派生したアカウントです。
    そのフレーズからウォレットをインポートすると、シードアカウントもまとめて復元されます。

外部アカウント
:   [秘密鍵](default:秘密鍵) からアプリにインポートされたアカウントです。
    外部アカウントはウォレットのニーモニックフレーズから復元されないため、個別にバックアップする必要があります。

## どこから始めるか

* まだアプリをインストールしていない場合は、[アプリのインストール](./install.md) を参照してください。
* 新しいウォレットを作成するには、[ウォレットの作成](./create-wallet.md) を参照してください。
* ニーモニックフレーズからウォレットを復元するには、[ウォレットのインポート](./import-wallet.md) を参照してください。
* 秘密鍵からアカウントを追加するには、[アカウントのインポート](./import-account.md) を参照してください。
