# 新しいウォレットの作成

このページでは、Symbol モバイルウォレットアプリで**新しい**ウォレットを作成する方法を説明します。
すでにバックアップフレーズがあり、既存のウォレットを復元したい場合は、代わりに
[ウォレットのインポート](./import-wallet.md) ガイドに従ってください。

アプリは 1 つのウォレット内で複数のアカウントを管理できます。
[別のアカウントを作成](./create-account.md)したいだけであれば、別のウォレットを作成する必要はない場合があります。

ウォレットとアカウントの詳細については、[はじめに](./intro.md) を参照してください。

## 前提条件

* Symbol モバイルウォレットがインストールされていることを確認してください。
    まだインストールしていない場合は、[アプリのインストール](./install.md) ガイドを参照してください。

!!! warning "有効にできるウォレットは一度に 1 つだけです"

    Symbol モバイルウォレットアプリは、一度に 1 つのウォレットを扱います。
    すでにウォレットが有効になっている場合、新しいウォレットを作成するオプションは表示されません。

    別のウォレットを作成するには、まず現在のウォレットから[ログアウト](./logout-wallet.md)してください。
    その前に、後で必要になった場合に復元できるよう、現在のウォレットの [ニーモニックフレーズ](default:ニーモニックフレーズ) を
    [バックアップ](./export-wallet.md)していることを確認してください。
    [外部アカウント](default:外部アカウント)が含まれている場合は、それらも[バックアップ](./export-account.md)していることを確認してください。

## ウォレットの作成方法

Symbol モバイルウォレットで新しいウォレットを作成するには、次の手順に従ってください。

{% import 'tutorial.jinja2' as tutorial %}

{{ tutorial.list_begin("portrait") }}

{{ tutorial.step_begin("create-wallet-0.webp") }}
Symbol モバイルウォレットを開き、**Create Wallet** をタップします。

ようこそ画面が表示されない場合は、すでにウォレットが有効です。その場合は[ログアウト](./logout-wallet.md)するか、
そのウォレット内で[アカウントを作成](./create-account.md)してください。
{{ tutorial.step_end() }}

{{ tutorial.step_begin("create-wallet-1.webp") }}
最初のアカウントの名前を入力します。

このラベルは、後でアカウントを識別するのに役立ちます。
デフォルト名のままにすることも、自分で選ぶこともできます。

**Next** をタップします。
{{ tutorial.step_end() }}

{{ tutorial.step_begin("create-wallet-2.webp") }}
**Show Mnemonic Phrase** をタップして、バックアップフレーズを表示します。

表示された順番どおりにフレーズを書き留めます。

**オフラインのバックアップ場所など、安全な場所に保管してください**。

保存したら、フレーズを失うリスクを承諾する確認ボックスにチェックを入れ、**Next** をタップします。
{{ tutorial.step_end() }}

{{ tutorial.step_begin("create-wallet-3.webp") }}
PIN コードを作成し、確認します。

この PIN は、デバイス上のウォレットへのアクセスを保護します。

覚えられるものを選び、誰とも共有しないでください。
{{ tutorial.step_end() }}

{{ tutorial.step_begin("create-wallet-4.webp") }}
アプリがウォレットの設定を完了するまで数秒待ちます。
{{ tutorial.step_end() }}

{{ tutorial.list_end() }}

**:material-home: HOME** 画面に移動します。

![ウォレットの作成成功](create-wallet-5.webp){ .tutorial-result }

最初のアカウントを使用する準備ができました。
アドレスを共有して資金を受け取ったり、アプリからトランザクションを送信したりできます。

## 次のステップ

新しいウォレットを使用する準備ができました。

* ニーモニックフレーズのバックアップを安全に保管してください。
* 必要に応じて、このウォレットに[さらにアカウントを追加](./create-account.md)できます。
* 資金の受け取りや送信を行う前に、[セキュリティ](../security.md) ガイドを確認してください。
