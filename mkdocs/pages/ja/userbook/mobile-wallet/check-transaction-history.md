# トランザクション履歴の確認

このページでは、Symbol モバイルウォレットアプリでアカウントのトランザクション履歴を確認する方法を説明します。

履歴画面には、選択したアカウントに関係する過去のトランザクションが表示されます。
たとえば、[資金とメッセージの送信](./send-funds-and-messages.md) の後に、送信者または受信者の視点で転送内容を確認できます。

## 前提条件

* Symbol モバイルウォレットがインストールされていることを確認してください。
    まだインストールしていない場合は、[アプリのインストール](./install.md) ガイドを参照してください。

* すでにウォレットが設定され、アプリでロック解除されている必要があります。
    必要に応じて、[ウォレットの作成](./create-wallet.md) または [ウォレットのインポート](./import-wallet.md) を参照してください。

## トランザクション履歴の確認方法

アカウントのトランザクション履歴を確認するには、次の手順に従ってください。

{{ tutorial.list_begin("portrait") }}

{{ tutorial.step_begin("create-wallet-5.webp") }}
ウォレットの **:material-home: HOME** 画面で、履歴を確認したいアカウントを選択します。

次に、下部の **:fontawesome-solid-history: HISTORY** をタップします。
{{ tutorial.step_end() }}

{{ tutorial.step_begin("transfer-6.webp") }}
履歴には、選択したアカウントに関係する過去のトランザクションが表示されます。

この例では **MY ACCOUNT** が選択されており、一番上のトランザクションは送信トランザクションです。

トランザクションをタップして詳細を開きます。
{{ tutorial.step_end() }}

{{ tutorial.step_begin("transfer-7.webp") }}
詳細には次の情報が表示されます。

* **STATUS**: トランザクションがすでに承認されているかどうか。
* **DATE**: トランザクションがアナウンスされた日時。ローカル時刻で表示されます。
* 転送された <XYM:> の量。
* 送信者と受信者のアドレス。どちらかのアドレスがアドレス帳に登録されている場合は、実際のアドレスの代わりに名前が表示されます。
* トランザクション **HASH**: 受信者と共有する際に役立ちます。
* **FEE**: トランザクションのコスト。
* **SIGNED-BY**: トランザクションをアナウンスし、手数料を支払ったアドレス。
    複数アカウントが関わる [アグリゲートトランザクション](default:アグリゲートトランザクション) で重要です。
* **:material-magnify: OPEN IN BLOCK EXPLORER** ボタン: ブロックチェーンエクスプローラーでトランザクションを開きます。

長い矢印をタップすると詳細を展開し、追加情報を確認できます。
{{ tutorial.step_end() }}

{{ tutorial.step_begin("transfer-9.webp") }}
展開された詳細には次の情報が表示されます。

* **SENDER** と **RECIPIENT** のアドレス。アドレス帳に登録されている場合は名前も表示されます。
* **MESSAGE**: トランザクションにメッセージが含まれている場合に表示されます。
* **MOSAICS**: 転送された [モザイク](default:モザイク) の完全な一覧。
    XYM 以外のモザイクを転送した場合に重要です。

**:material-arrow-left: 戻る矢印** をタップして、トランザクション履歴画面に戻ります。
{{ tutorial.step_end() }}
