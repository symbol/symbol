# 既存ウォレットのインポート

このページでは、[ニーモニックフレーズ](default:ニーモニックフレーズ) を使用して、**既存の**ウォレットを Symbol モバイルウォレットアプリにインポートする方法を説明します。
新しいウォレットを最初から作成したい場合は、[ウォレットの作成](./create-wallet.md) ガイドを参照してください。

アプリ内のウォレットとアカウントの詳細については、[はじめに](./intro.md) を参照してください。

## 前提条件

* Symbol モバイルウォレットがインストールされていることを確認してください。
    まだインストールしていない場合は、[アプリのインストール](./install.md) ガイドを参照してください。

* インポートしたいウォレットのニーモニックフレーズを用意してください。

    Symbol は [BIP39](https://github.com/bitcoin/bips/blob/master/bip-0039.mediawiki) 標準を使用しています。
    これは、標準化された単語リストから選ばれた 24 個の英単語でニーモニックを表現するものです。

!!! warning "有効にできるウォレットは一度に 1 つだけです"

    Symbol モバイルウォレットアプリは、一度に 1 つのウォレットのみを扱います。
    すでにウォレットが有効になっている場合、ウォレットをインポートするオプションは表示されません。

    別のウォレットをインポートするには、まず現在のウォレットから[ログアウト](./logout-wallet.md)してください。
    その前に、後で必要になった場合に復元できるよう、現在のウォレットの [ニーモニックフレーズ](default:ニーモニックフレーズ) を
    [バックアップ](./export-wallet.md)していることを確認してください。
    [外部アカウント](default:外部アカウント)が含まれている場合は、それらも[バックアップ](./export-account.md)していることを確認してください。

## ウォレットのインポート方法

Symbol モバイルウォレットに既存のウォレットをインポートするには、次の手順に従ってください。

![ウォレットのインポート成功](create-wallet-5.webp){ .tutorial-result }

インポートしたウォレットを使用する準備ができました。
アカウントアドレスを共有して資金を受け取ったり、アプリからトランザクションを送信したりできます。

## 次のステップ

このデバイスでウォレットを使用できるようになりました。

* ニーモニックフレーズのバックアップを安全に保管してください。
* 必要に応じて、このウォレットに[さらにアカウントを追加](./create-account.md)できます。
* 外部アカウントを復元するには、[個別にインポート](./import-account.md)してください。
* 資金の受け取りや送信を行う前に、[セキュリティ](../security.md) ガイドを確認してください。
