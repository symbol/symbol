# アカウントのインポート

このページでは、[秘密鍵](default:秘密鍵) を使用して、既存の [アカウント](default:アカウント) を Symbol モバイルウォレットアプリの有効なウォレットにインポートする方法を説明します。

インポートされたアカウントは[外部アカウント](default:外部アカウント)です。
ウォレットの [ニーモニックフレーズ](default:ニーモニックフレーズ) から派生したものではないため、ウォレットバックアップからは復元できません。
必ず[秘密鍵を別にバックアップ](./export-account.md)してください。

代わりにウォレットのニーモニックフレーズから別のアカウントを作成したい場合は、[アカウントの作成](./create-account.md) に従ってください。

## 前提条件

* Symbol モバイルウォレットがインストールされていることを確認してください。
    まだインストールしていない場合は、[アプリのインストール](./install.md) ガイドを参照してください。

* すでにウォレットが設定され、アプリでロック解除されている必要があります。
    必要に応じて、[ウォレットの作成](./create-wallet.md) または [ウォレットのインポート](./import-wallet.md) を参照してください。

* インポートしたいアカウントの秘密鍵を用意してください。
    秘密鍵は 64 文字の 16 進数です。数字と `a` から `f` までの英字で構成されます。
    英字は大文字でも小文字でもかまいません。

!!! warning "秘密鍵をバックアップしてください"

    外部アカウントは、ウォレットのニーモニックフレーズバックアップには含まれません。
    秘密鍵を失うと、アカウントへのアクセスを失う可能性があります。

## 次のステップ

インポートしたアカウントをアプリで使用できるようになりました。
選択すると使用を開始できます。

* 秘密鍵のバックアップは安全に保管し、ウォレットのニーモニックフレーズバックアップとは分けてください。
* 後でアプリからこの秘密鍵をバックアップする必要がある場合は、[外部アカウントのエクスポート](./export-account.md) に従ってください。
* **:material-home: HOME** 画面のアカウントドロップダウンから、アカウントを切り替えることができます。
* インポートしたアカウントをアプリから削除したい場合は、[アカウントの削除](./delete-account.md) に従ってください。
