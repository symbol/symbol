# 外部アカウントのエクスポート

このページでは、[秘密鍵](default:秘密鍵) をエクスポートして、Symbol モバイルウォレットアプリの[外部アカウント](default:外部アカウント)をバックアップする方法を説明します。

[シードアカウント](default:シードアカウント)はウォレットの [ニーモニックフレーズ](default:ニーモニックフレーズ) から派生するため、
[ウォレットバックアップフレーズをエクスポート](./export-wallet.md)するとバックアップされます。
外部アカウントは異なります。秘密鍵からアプリにインポートされたもので、ウォレットのニーモニックフレーズバックアップには含まれません。
外部アカウントをバックアップするには、ここに示すように秘密鍵を手動でエクスポートしてください。

!!! danger "秘密鍵は秘密にしてください"

    アカウントの秘密鍵を持っている人は誰でも、そのアカウントを制御できます。
    秘密鍵は絶対に共有せず、バックアップは安全かつオフラインで保管してください。

## 前提条件

* Symbol モバイルウォレットがインストールされていることを確認してください。
    まだインストールしていない場合は、[アプリのインストール](./install.md) ガイドを参照してください。

* すでにウォレットが設定され、アプリでロック解除されている必要があります。
    必要に応じて、[ウォレットの作成](./create-wallet.md) または [ウォレットのインポート](./import-wallet.md) を参照してください。

* 有効なウォレットに外部アカウントが必要です。
    必要に応じて、[アカウントのインポート](./import-account.md) を参照してください。

* ウォレットの PIN コードが必要です。

## 外部アカウントのエクスポート方法

外部アカウントの秘密鍵を表示してコピーするには、次の手順に従ってください。

{% import 'tutorial.jinja2' as tutorial %}

{{ tutorial.list_begin("portrait") }}

{{ tutorial.step_begin("export-account-1.webp") }}
ウォレットの **:material-home: HOME** 画面で、エクスポートしたい外部アカウントを選択します。

アカウントボックス左側の **:fontawesome-regular-user: DETAILS** をタップします。
{{ tutorial.step_end() }}

{{ tutorial.step_begin("export-account-2.webp") }}
**DETAILS** ボックスで、**ACCOUNT TYPE** が `external` であることを確認します。

そうでない場合は、[ウォレットのエクスポート](./export-wallet.md) ガイドに従ってください。

**:octicons-key-24: REVEAL PRIVATE KEY** をタップします。
{{ tutorial.step_end() }}

{{ tutorial.step_begin("export-wallet-3.webp") }}
PIN コードを入力してウォレットのロックを解除します。
{{ tutorial.step_end() }}

{{ tutorial.step_begin("export-account-4.webp") }}
秘密鍵が表示されます。

**:material-content-copy: COPY** をタップしてコピーします。
{{ tutorial.step_end() }}

{{ tutorial.list_end() }}

秘密鍵はクリップボードにコピーされましたが、まだバックアップされたわけではありません。
安全でオフラインの場所に保管するか、印刷してハードコピーを安全な場所に保管してください。

* 秘密鍵は、チャット、メール、その他の第三者がアクセスできる可能性のある手段では絶対に送信しないでください。
* 秘密鍵のバックアップは、複数の安全な場所に分けて保管してください。

## 次のステップ

* この秘密鍵を別のウォレットにインポートするには、[アカウントのインポート](./import-account.md) を参照してください。
