# アカウントの作成

このページでは、Symbol モバイルウォレットアプリの有効なウォレットに別な [アカウント](default:アカウント) を追加する方法を説明します。

この方法で作成されるアカウントは[シードアカウント](default:シードアカウント)です。
ウォレットの [ニーモニックフレーズ](default:ニーモニックフレーズ) から派生するため、同じウォレットバックアップから後で復元できます。

別なウォレットから既存のアカウントをインポートしたい場合は、その [秘密鍵](default:秘密鍵) と
[アカウントのインポート](./import-account.md) チュートリアルを参照してください。

## 前提条件

* Symbol モバイルウォレットがインストールされていることを確認してください。
    まだインストールしていない場合は、[アプリのインストール](./install.md) ガイドを参照してください。

* すでにウォレットが設定され、アプリでロック解除されている必要があります。
    必要に応じて、[ウォレットの作成](./create-wallet.md) または [ウォレットのインポート](./import-wallet.md) を参照してください。

## 次のステップ

新しいアカウントを使用する準備ができました。
選択すると使用できます。

* **:material-home: HOME** 画面のアカウントドロップダウンから、アカウントを切り替えることができます。
* シードアカウントをアカウント一覧から非表示にしたい場合は、[アカウントの削除](./delete-account.md) を参照してください。
* ウォレットのニーモニックフレーズをまだバックアップしていない場合は、[ウォレットのエクスポート](./export-wallet.md) を参照してください。
