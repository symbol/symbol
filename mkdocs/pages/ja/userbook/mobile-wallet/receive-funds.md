# 資金の受け取り

資金を受け取るには、自分のアカウントの [アドレス](default:アドレス) を送信者に共有します。

アドレスは **:material-home: HOME** 画面のアカウントボックス内に表示されます。
アドレスの横にある **:material-content-copy: コピーボタン** を使用してコピーします。

![ホーム画面](create-wallet-5.webp){ .tutorial-result }

送信者も Symbol モバイルウォレットを使用している場合は、[QR コードでアドレスを共有](./share-address-qr-code.md)すると便利です。
