# Symbol モバイルウォレットアプリのインストール

Symbol モバイルウォレットの最新版は、デバイスのアプリストアからダウンロードできます。

[:simple-android:](#){ .md-button }
[:simple-ios:](#){ .md-button }

## 次のステップ

Symbol モバイルウォレットをインストールしたら、アカウントを管理できるようにウォレットを作成またはインポートする必要があります。

* 新しいウォレットとアカウントを設定するには、[ウォレットの作成](./create-wallet.md) ガイドに従ってください。
* ウォレットとそのシードアカウントを復元するには、[ウォレットのインポート](./import-wallet.md) ガイドに従ってください。
* [秘密鍵](default:秘密鍵) から外部アカウントを復元するには、[アカウントのインポート](./import-account.md) ガイドに従ってください。
