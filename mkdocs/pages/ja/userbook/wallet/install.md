# Symbol Desktop Wallet のインストール

## 概要

Symbol Desktop Wallet は、Symbol ブロックチェーンとやり取りするために使用されるグラフィカルアプリケーションです。
複数の <account:|アカウント> の管理、トランザクションの送受信、<Multisignature Account:|マルチシグ> 操作の署名、メタデータの表示などが可能です。

ウォレットには2つのバージョンがあります。

* **ネイティブアプリケーション**: Windows、macOS、および Linux で利用可能な、インストール型のデスクトップアプリ。
* **Webアプリケーション**: 同じコア機能を持つブラウザベースのバージョンですが、Ledger ハードウェアウォレットは**サポートしていません**。

ウォレットのインターフェースは、英語、日本語、中国語、韓国語、ロシア語など、複数の言語で利用できます。

## インストール方法

Symbol Desktop Wallet の最新バージョンは、公式のリリースページからダウンロードできます。

[GitHubからダウンロード](https://github.com/symbol/desktop-wallet/releases){ .md-button }

### ネイティブバージョンのインストール

1. リリースページにアクセスし、お使いのオペレーティングシステム用のインストーラーをダウンロードします。
2. インストーラーを起動し、プラットフォームごとのインストール手順に従います。

インストールが完了すると、デスクトップまたはアプリケーションフォルダからアプリケーションを開くことができます。

### ブラウザバージョンのインストール

1. リリースページにアクセスし、 `.all.zip` ファイルをダウンロードします。
2. 内容を新しいフォルダに展開（解凍）します。
3. `index.html` ファイルをダブルクリックします。

後ですばやくアクセスできるように、このファイルへのショートカットを作成しておくことができます。

## 次のステップ

Symbol Desktop Wallet のインストールが完了したら、アカウントを整理して管理できるように、プロファイルを作成またはインポートする必要があります。

* 新しいプロファイルとアカウントを設定するには、[プロファイルの作成](./create-profile.md) チュートリアルを参照してください。
* 既存のアカウントを復元するには、[プロファイルのインポート](./import-profile.md) チュートリアルを参照してください。
