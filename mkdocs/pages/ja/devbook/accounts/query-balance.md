# アカウント残高の照会

Symbol上の [アカウント] (default: アカウント) は、ネットワークのネイティブ通貨である [XYM] (default: XYM) を含む [モザイク] (default: モザイク)（代替可能トークン）を保持できます。 [cite: 1, 3]

このチュートリアルでは、アカウントのモザイク残高を照会し、適切な小数点以下の桁数で表示する方法を説明します。 [cite: 3]
[モザイクID] (default: モザイクID) にリンクされた [ネームスペース] (default: ネームスペース) がある場合、それも取得してモザイクのフレンドリーネームとして表示します。 [cite: 3]

## 前提条件

このチュートリアルでは、SDKを必要とせずに [Symbol REST API](../reference/rest/symbol.md) を使用します。 [cite: 4]
HTTPリクエストを行う方法さえあれば実行可能です。 [cite: 4]

## コード解説

### アカウント情報の取得

{{ tutorial.code_snippet(['py:10:33', 'js:6:32']) }}

<get:/accounts/{accountId}> エンドポイントは、保持しているすべてのモザイクを含むアカウントの状態を取得します。 [cite: 6]

[アドレス] (default: アドレス) または [公開鍵] (default: 公開鍵) のいずれかを使用してアカウントを照会できます。 [cite: 6]

### モザイク名の取得

{{ tutorial.code_snippet(['py:36:60', 'js:34:57']) }}

モザイクは64ビットの数値である [モザイクID] (default: モザイクID) によって識別されますが、これは読みにくく覚えにくい場合があります。 [cite: 7]
利便性を高めるために、モザイクを人間が読み取り可能な [ネームスペース] (default: ネームスペース) エイリアスにリンクさせることができます。 [cite: 7]

<post:/namespaces/mosaic/names> エンドポイントは、複数のモザイクIDを受け取り、現在それらにリンクされているネームスペース名を返します。 [cite: 7]
モザイクにリンクされたネームスペースがない場合、そのモザイクはレスポンスに含まれません。 [cite: 7]

1つのモザイクに複数のネームスペースエイリアスが存在する場合もあります（異なるネームスペースが同じモザイクにリンクできるため）。 [cite: 7]
この場合、コードではすべてのエイリアスをカンマで区切って表示します。 [cite: 7]

### モザイクプロパティの取得

{{ tutorial.code_snippet(['py:63:87', 'js:59:82']) }}

モザイク残高を正しくフォーマットするために、スニペットはネットワークからプロパティを取得します。 [cite: 8]
必要な主要プロパティは [可分性] (default: 可分性) であり、これはモザイクがサポートする小数点以下の桁数を定義します。 [cite: 8]

個別のモザイクについては <get:/mosaics/{mosaicId}> エンドポイントを使用してプロパティを取得できます。 [cite: 8]
このスニペットで使用されているオプションは <post:/mosaics> エンドポイントで、1回のリクエストで複数のモザイクIDを受け取り、可分性を含む各モザイクの詳細情報を返します。 [cite: 8]

### 金額のフォーマット

{{ tutorial.code_snippet(['py:90:105', 'js:84:101']) }}

このユーティリティ関数は、*絶対量 (atomic amount)* を人間にとってわかりやすい表現に変換します。 [cite: 9]

* **絶対量 (Atomic amount):** ブロックチェーン上に保存される生の数値で、整数として表されます。 [cite: 9]
* **フォーマット済みの金額 (Formatted amount):** モザイクの可分性によって決定される小数点以下の桁数を持つ表示形式。 [cite: 9]

フォーマット処理では、$10^{\text{可分性}}$ で除算し、その余りを取ることで、絶対量を整数部分と小数部分に分割します。 [cite: 9]
小数部分は、常に正しい小数点以下の桁数が表示されるようにゼロパディングされます。 [cite: 9]

### すべてを組み合わせる

{{ tutorial.code_snippet(['py:108:150', 'js:103:148']) }}

メインコードは `ADDRESS` 環境変数を読み取って、どのアカウントを照会するかを決定します。 [cite: 10]
値が指定されない場合は、デフォルトのサンプルアドレスを使用します。 [cite: 10]

ヘルパー関数を以下のように連携させます。 [cite: 10]

1. アカウント情報を取得する。 [cite: 10]
2. アカウントからモザイクIDを抽出する。 [cite: 10]
3. すべてのモザイクのプロパティとネームスペース名を取得する。 [cite: 10]
4. 各モザイクをループし、適切な小数点以下の桁数で残高をフォーマットする。 [cite: 10]

## 出力

以下に示す出力は、プログラムの典型的な実行結果に対応しています。 [cite: 11]

```text
--8<-- 'devbook/accounts/query-balance.log'
```

出力には、アカウントが保持するすべてのモザイクが表示されます。モザイクごとに可分性の値が異なることに注目してください。 [cite: 11]

* 1つ目のモザイクは可分性が6で、小数点以下6桁が表示されています (`592.589332`)。 [cite: 11]
    また、フレンドリーネーム (`symbol.xym`) を持っており、これがネットワークのネイティブ通貨であることを示しています。 [cite: 11]
* 2つ目は可分性が0で、小数点以下が表示されていません (`999999`)。 [cite: 11]
* 3つ目は可分性が2で、小数点以下2桁が表示されています (`0.01`)。 [cite: 11]
