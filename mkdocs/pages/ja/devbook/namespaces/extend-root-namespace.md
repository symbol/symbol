# ルートネームスペースの延長 {: #extending-a-root-namespace }

[ルートネームスペース](default:ネームスペース) は、1回の登録につき最大5年間の限定された [有効期間](../../textbook/namespaces.md#duration) でレンタルされます。最初のレンタル期間を超えてネームスペースを保持したい場合は、延長を行う必要があります。

このチュートリアルでは、ルートネームスペースを延長する方法を説明します。

## 前提条件 {: #prerequisites }

* 有効なルートネームスペースを所有する [アカウント](default:アカウント)。
    [ルートネームスペースの登録](./register-root-namespace.md) を参照してください。
* トランザクション手数料およびレンタル手数料を支払うための [XYM](default:XYM)。

## 延長のタイミング {: #when-to-extend }

ネームスペースは以下の2つの状況で延長できます。

* **有効期間中:** 指定された期間が現在のレンタル期間に加算され、有効期限がさらに先に延びます。

* **猶予期間中:** ネームスペースは期限切れになっていますが、まだ [猶予期間](../../textbook/namespaces.md#duration) 内にある場合、延長することで即座に有効な状態に戻すことができます。

!!! note "サブネームスペースの延長"

    延長が必要なのはルートネームスペースのみです。
    [サブネームスペース](default:ネームスペース) はルートネームスペースの有効期間を継承するため、ルートネームスペースを延長すると、そのすべてのサブネームスペースも自動的に延長されます。

## ステップ・バイ・ステップ {: #step-by-step }

ネームスペースを延長するには、以下のパラメータを使用して [登録プロセス](./register-root-namespace.md) を繰り返します。

1. 既存のネームスペースと **同じネームスペース名** を使用します。
2. `registration_type` を `root` に設定します。
3. 現在のレンタル期間に加算する **有効期間**（ブロック数）を指定します。

トランザクションに署名するアカウントは、ネームスペースの所有者である必要があります。

## 有効期間と制限 {: #duration-and-limits }

1回の延長で最大 5,256,000 ブロック（約5年）を加算できます。
ただし、残りの総有効期間が将来に向かって5年を超えることはできません。
例えば、ネームスペースの期限が3年後に切れる場合、最大で2年分しか加算できません。

ネームスペースを無期限に維持するには、定期的に延長を行ってください。

詳細については、テキストブックの [有効期間](../../textbook/namespaces.md#duration) を参照してください。
