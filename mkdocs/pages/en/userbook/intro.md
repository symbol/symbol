# Welcome to the User Manual

This manual explains how to perform common tasks on the Symbol blockchain using the applications maintained by
the Symbol Syndicate.
**No coding is required.**

Each page in this manual describes how to complete a single task.
Instructions are presented in numbered steps, with screenshots and links to the [Textbook](../textbook/intro.md)
for background information when needed.
