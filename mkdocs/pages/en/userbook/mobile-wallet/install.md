# Installing the Symbol Mobile Wallet App

![Welcome screen](create-wallet-0.webp){ .tutorial-result }

## What Is It

The Symbol Mobile Wallet is a graphical application used to interact with the Symbol blockchain from
an Android or iOS device.
It allows its users to manage multiple <accounts:>, send and receive transactions,
bridge <XYM:> tokens to other blockchains, and more.

## How to Install It

You can download the latest version of the Symbol Mobile Wallet from your device's app store:

## Next Steps

After the Symbol Mobile Wallet is installed, you need to create or import a wallet so you can keep your accounts
organized.

* To set up a new wallet and account, follow the [Creating a Wallet](./create-wallet.md) guide.
* To restore existing accounts, follow the [Importing a Wallet](./import-wallet.md) guide.
