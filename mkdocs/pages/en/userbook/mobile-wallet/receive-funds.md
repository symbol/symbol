# Receiving Funds

To receive funds, share your account's <address:> with the sender.

The address is shown on the **:material-home: HOME** screen, inside the account box.
Use the **:material-content-copy: copy button** next to the address to copy it.

![Home screen](create-wallet-5.webp){ .tutorial-result }

If the sender is also using the Symbol Mobile Wallet, it's more convenient to
[share the address using a QR code](./share-address-qr-code.md).
